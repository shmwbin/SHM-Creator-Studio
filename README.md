# SHM Creator Studio Pro

A next-generation, Bengali-first Creator Tools MVP for SHM Digital Hub (`shmwb.in`), built for India's Orange Economy.

## Included Files in this Repository

- `index.html` — Advanced landing page, responsive navigation, and modal interactive workspace.
- `assets/css/style.css` — Modern glassmorphism UI, glowing ambient gradients, and fully responsive grid layout.
- `assets/js/app.js` — Client-side logic, high-resolution poster canvas rendering, multi-format export tools, and SEO inspector.

## Featured Tools & Utilities

1. **AI Social Media Post Maker** — Live poster canvas preview, custom background gradients, image upload support, and instant PNG download.
2. **Smart Bangla Caption Studio** — Template-based professional Bengali caption drafts for social posts, videos, and festivals.
3. **Digital E-Book & PDF Maker** — Clean document formatting with print-to-PDF support.
4. **Interactive Portfolio Builder** — Live preview, HTML web file download, and clean typography.
5. **Business Quotation & Price Kit** — Micro-business quotation, invoice, and service price list generator.
6. **Creator SEO & Meta Inspector** — Real-time title/description length checker and meta tag generator.

## How to Publish & Use

1. Create a dedicated folder in your GitHub repository (e.g., `creator-studio`).
2. Upload `index.html`, `README.md`, and the `assets/` folder (containing `css/style.css` and `js/app.js`).
3. Open `index.html` locally in any modern browser to test instantly.
4. Publish via GitHub Pages or your custom domain hosting mapped to `shmwb.in`.

## Technical & Privacy Notes

- **Client-Side Architecture:** No backend server or third-party database is required; all processing happens locally inside your browser.
- **Privacy First:** User inputs and generated drafts remain entirely private on your device.
- **Export Formats:** Supports PNG image downloads, HTML file generation, and browser-based PDF printing.
